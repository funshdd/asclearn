# 不断电升级（ISP）操作说明

本目录的「电脑升级工具」由两部分组成：

| 文件 | 用途 |
|---|---|
| `lock_console.py` | 串口控制台 / 自动回归自测，用来触发 `ISP` 命令并观察 `OK ISP` |
| 本文档 | 用官方 STC-ISP 完成真正的下载与校验 |

> 原理：程序在**解锁状态**收到 `ISP` 后回 `OK ISP`，等串口发完再等 500 ms，然后 `ISP_CONTR = 0x60`
> 软复位进入芯片内部的 ISP 引导区。整个过程**不断电**，因此 STC-ISP 必须在单片机复位前
> 就处于「正在检测目标单片机」的等待状态。

---

## 一、标准流程（推荐）

1. **烧好 A 版**（`HEX/A_D8_OFF.hex`），上电，确认数码管显示 `0 0 - - - - - -`。
2. 打开 STC-ISP：
   - 单片机型号：`STC89C52RC / STC89C52RC Series`
   - 串口号：与 `lock_console.py` 同一 COM 口
   - 最低波特率 `2400`，最高波特率 `115200`（更高也可以）
   - 打开 `HEX/B_D8_ON.hex`
3. 点击 STC-ISP 的 **「下载/编程」**，界面提示「正在检测目标单片机…」——此时**不要**断电。
4. 用 `lock_console.py` 让板子进入解锁态并触发升级：

   ```
   python Tools\lock_console.py --port COM3
   > STATUS                     <- 应为 OK LOCKED 0 0 0 0
   > DIGIT 0
   ...
   > DIGIT 5
   > OK                         <- OK UNLOCKED 0 0 0 15
   > ISP                        <- 期望回复 OK ISP
   ```

   也可以用矩阵键盘解锁（`012345` 后按 `S4` 确认），再在控制台敲 `ISP`。

5. 500 ms 后芯片自动软复位进入 ISP，STC-ISP 完成握手 → 下载 → 校验。
   数码管在这 500 ms 内显示状态码 `6`（升级准备）。
6. 下载成功后程序自动运行 B 版：数码管回到 `0 0 - - - - - -`（**锁定**），
   **密码仍是升级前保存的那个**（没改过就是 `012345`），并且可以再做一次升级。

---

## 二、注意事项

- **只能解锁后升级**：`LOCKED / NEW1 / NEW2 / WAIT / PROTECT` 下发 `ISP` 一律回 `ERR DENIED`。
- 若软复位后 STC-ISP 报「握手失败」，通常是工具没有提前进入等待状态；重新点一次「下载/编程」，
  再发一次 `ISP` 即可。仍失败时断电重上电属于正常下载流程（本功能只是省掉断电动作）。
- 升级过程中 EEPROM 不擦除，所以**千万不要**用「擦除用户 EEPROM」选项，否则密码会回到默认值。
- 升级完成后建议跑一遍 `python Tools\lock_console.py --port COM3 --test` 确认业务功能正常。

---

## 三、回退到 A 版

重复上面流程，第 2 步把 HEX 换成 `HEX/A_D8_OFF.hex` 即可。评测最后要求「恢复默认密码、最终运行 B」，
所以正式提交前请确认板子上运行的版本符合要求。
