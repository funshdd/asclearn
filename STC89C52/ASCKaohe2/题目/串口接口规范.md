# 串口接口规范

除 VERSION、成功 ISP 外，每条命令回复一行，CRLF 结束：

OK \<state\> \<count\> \<errors\> \<remaining\> \<idle\>

ERR \<code\> \<state\> \<count\> \<errors\> \<remaining\> \<idle\>

字段用一个空格隔开。数字为十进制不补零：count=当前输入位数；errors=错误次数；remaining=暂停/保护剩余秒数，其他为 0；idle=解锁/改密距自动上锁剩余秒数，其他为 0。秒数向上取整。只返回位数，不返回密码。

state：`LOCKED`、`UNLOCKED`、`NEW1`、`NEW2`、`WAIT`、`PROTECT`。

code：`BAD_CMD` 非法整行；`INCOMPLETE` 输入不足；`WRONG` 密码错误；`FULL` 输入已满；`DENIED` 当前状态不允许；`MISMATCH` 两次新密码不同；`STORAGE` 保存失败。

例：`ERR WRONG WAIT 0 3 30 0` 表示第三次错误后进入 30 秒暂停。回复是处理后的状态。100 ms 内开始反馈，250 ms 内回复完；不要求应对人为丢字节或串口断连。

业务规则：

- LOCKED/NEW1/NEW2 接受数字、DEL、CLEAR、OK。六位已满拒绝新增；不足六位确认保留输入，不增加次数。DEL/CLEAR 对空输入成功但无变化。

- UNLOCKED 拒绝数字、DEL、CLEAR、OK；CHANGE 仅在 UNLOCKED 开始修改。NEW1 满六位确认进入 NEW2 并清空本次输入；NEW2 一致则保存，不一致返回 MISMATCH，两种情况均清空输入并回 UNLOCKED，原密码仅在保存成功时更改。

- CANCEL 在改密时丢弃暂存、回 UNLOCKED；其他非限制状态成功但无变化。LOCK 清除输入并锁定，WAIT/PROTECT 中只保持原限制。

- WAIT/PROTECT 拒绝所有输入、改密、取消、ISP，允许 STATUS/VERSION。30 秒结束后仍为 3 次，第四次错误不再暂停，第五次进入保护；60 秒保护结束后清零。

- 有效且改变输入或阶段的操作刷新 15 秒计时；查询、非法、拒绝、空删除/清空、不足确认、输入已满均不刷新。到期优先于同时到达的业务操作。声光提示不延长计时。

- 第三次暂停结束标志也须保存，不能重启后只因次数仍为 3 再暂停。密码最终提交时断电，允许恢复完整旧值或完整新值，禁止半个密码。

版本回复：`OK VERSION <version>`，version 为 1～16 个字母、数字、点、短横线或下划线。

ISP：电脑发送 `49 53 50 0A`；允许时返回 `OK ISP`，串口实际发送完成后，非阻塞等待 **500 ms** 让电脑接管，再向 STC89C52RC 的 `ISP_CONTR`（地址 `0xE7`）写 `0x60`。其他状态回复通用 ERR DENIED，不得通过串口控制线强制下载。准备期间业务暂停，扫描仍工作；进入 ISP 后显示允许熄灭。

首次烧录关闭上电看门狗、关闭“下载擦除 EEPROM”；时钟模式按实际编译设置一致。建议使用板载 24C02 保存密码。升级后保留密码、锁定、零输入，新程序正常响应 VERSION 和下一次 ISP。

声光：普通操作响/亮 30 ms；解锁和保存成功两次 50 ms、中隔 50 ms；错误/拒绝 200 ms；进入限制三次 100 ms、中隔 100 ms。D7/P2\.6 低电平亮。密集事件合并，限制提示优先；不能阻塞业务。蜂鸣器需根据实物有源/无源类型驱动。
